# B-14 — COMBINED_PARAMETER mapping for HmIP blind/slat actuators

**✅ done 2026-09-02** (`4.1.0-dev.5`) — issues #136, #154, #175.

HmIP blind actuators accept but ignore a lone LEVEL_2 (slat position)
write; the CCU itself writes the COMBINED_PARAMETER datapoint as
percent pairs. `nodes/lib/combined.js` maps LEVEL_2 setValue calls to
`COMBINED_PARAMETER` `L2=<percent>` (native 0..1 scale × 100, rounded)
whenever the channel's VALUES description carries COMBINED_PARAMETER —
hooked at the top of `ccu-connection.setValue()`, so the value,
set-value, mqtt and queued paths are all covered. A lone `L2=` leaves
the height unchanged (per the working examples in #154; the WebUI's
`L=101` marker does not work). 6 unit tests; guarded to never remap
when the description lacks COMBINED_PARAMETER, the value is
unparseable, or the datapoint is anything but LEVEL_2.

Not yet verified on real hardware — reporters asked to confirm with a
4.1.0 pre-release / after release.
